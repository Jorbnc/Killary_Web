Política de privacidad

Esta política explica cómo se trata la información al visitar el sitio web de Killary.

Última actualización: 25 de septiembre de 2026

1. Alcance y responsable

Esta página se aplica a este sitio informativo de Killary. Su responsable de publicación es jorbnc. Los datos que se faciliten en otros canales se tratarán según la finalidad y las condiciones de esos canales.

2. Información durante la visita

Este sitio no dispone de formularios, cuentas de usuario, pagos ni suscripciones. No solicita datos personales para consultar su contenido.

Las páginas no incorporan herramientas de analítica, publicidad, cookies propias ni scripts de seguimiento. Sus recursos visuales se sirven desde el mismo sitio.

3. Alojamiento y datos técnicos

El sitio se aloja en GitHub Pages. Para servir y proteger las páginas, GitHub puede procesar datos técnicos como la dirección IP, información del navegador y registros de solicitudes. Ese tratamiento y sus plazos de conservación se rigen por la política de privacidad de GitHub.

4. Contacto y enlaces externos

Al seguir un enlace a otro sitio, se aplican las condiciones y la política de privacidad de ese servicio. Si contactas al responsable mediante un canal externo, comparte únicamente la información necesaria para atender tu consulta. Evita publicar datos personales sensibles en espacios públicos.

5. Consultas y cambios

Para consultas relacionadas con este sitio, consulta el perfil del responsable. Si se incorporan formularios u otras funciones que traten datos personales, esta política se actualizará para explicar su finalidad y funcionamiento. La fecha indicada identifica la última actualización.
